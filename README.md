## 版本更新

需要 Python 3；抓取需要网络。Node用于纯逻辑回归检查。

```sh
# 获取来源最新赛季/补丁，完整抓榜，再获取当期S/A详情；仅生成预览
python3 scripts/knowledge/refresh.py

# 查看命令输出的快照路径与releases页面后，发布到本地当前入口
python3 scripts/knowledge/refresh.py --snapshot data/knowledge/jcc/set18/18.3/NEW_TIMESTAMP --publish

# 校验交付与匹配逻辑
python3 scripts/validate_release.py
node scripts/knowledge/test_engine.cjs
```

也可用 `--set 18 --patch 18.3` 指定来源版本。每次创建独立时间戳；已发布快照拒绝覆盖。发布命令不自动提交Git、不自动部署、不创建定时任务。采集失败会阻止发布，禁止拿旧版数据填补缺口。

## 数据组织

- `scripts/knowledge/`：采集、归一化、校验、生成、发布流水线。
- `templates/`：共享页面、独立助手及纯匹配引擎。
- `data/knowledge/jcc/赛季/补丁/时间戳/raw/`：全部原始响应。
- 同级 `manifest.json`：请求URL、抓取时间、哈希、覆盖与限制；`knowledge.json`：归一化知识库及反向索引。
- `data/knowledge/releases.json`：发布目录与当前指针。
- `releases/`：每个已生成版本的独立页面。
- `data/comps/`、`data/equipment/`、`data/versions/`、`data/refresh/`：迁移前历史证据。

## 数据口径与边界

当前来源为[金铲铲大数据](https://www.dataj.cc/comp)，非官方来源。233次请求成功，归一化15套阵容、285组分等级棋盘。前后版本比较为同一来源的18.2a与18.3查询，按ID及阵容定义核对；定义变化不直接计算改善，样本不足1,000另行标记。

来源没有公开段位和统计时间窗；推荐强化最多返回10项、每级棋盘通常3组、棋子三件套存在200条上限。保留全部返回记录不代表穷尽游戏内所有可能。

本次非挂件棋子返回的S/A三件套较少，界面将“来源推荐出装”与“S/A统计组合”分开。无评级或C/D的推荐配装不冒充S/A；第一章装备泛用性按来源推荐装备覆盖阵容数和件数计算。装备6079无法映射，归档但不作为推荐。主坦候选依据承装推定，运营时间为建议；分等级独立记录不是同一局的转型轨迹。

## 交互原则

当前过渡按当前等级匹配；后续方向独立查询目标等级。当前完整棋盘列出全部已收录终局归属；未来按缺失棋子频率提示补牌，继续多选后只保留兼容的真实组合。换等级保留棋子；转职缺失单列条件；强化只展示当期推荐并集。主C和主坦装备优先，装备补全支持重复件。正文折叠默认收起，章节和阵容索引保持展开。
